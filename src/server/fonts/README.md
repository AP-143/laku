# Fonts

`Geist-Regular.ttf` is the font the video captions are drawn with (see `src/server/video-join.ts`). It is Geist by Vercel, licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), and was copied from the Next.js package (`next/dist/compiled/@vercel/og`) so the captions do not depend on the fonts of the machine.
